# SUNSCRYPT — эксплуатация

Сервер общий (devuz.studio и др.): только проект Compose `-p sunscrypt`,
свой порт и сайт nginx. Все команды — от root в `/opt/sunscrypt`:

```sh
C="docker compose -p sunscrypt --env-file /opt/sunscrypt/.env -f infra/docker-compose.yml"
```

## Что работает по расписанию

`/etc/cron.d/sunscrypt` ставит выкатка (`infra/deploy.sh`), правки руками
затрутся. Вывод — в журнал системы: `journalctl -t sunscrypt`.

| Когда (UTC) | Что | Где итог |
|---|---|---|
| каждые 5 мин | наблюдение `app.watch`: сигналы и исполнители живы, ключи в порядке, журнал сходится с Bybit | админка → «Наблюдение» |
| 03:41 ежедневно | копия базы `infra/backup.sh` (14 дней) | `/opt/sunscrypt/backups` |
| 04:23 ежедневно | контроль дрейфа модели | админка → «Модель» |
| вс 01:13 | дообучение с проверкой (≈ 40–60 мин, 2 ядра) | админка → «Модель» |
| 05:17 ежедневно | новые версии NautilusTrader (GitHub Actions `nautilus-check.yml`) | задача в Actions |

## Резервные копии

Перед каждой выкаткой и ежедневно. Ключи Bybit в базе зашифрованы
`MASTER_KEY` из `.env`; рядом с копиями лежит `env.latest` — копия без него
бесполезна. Обе только для root.

Восстановление:

```sh
$C stop orchestrator signals backend
$C exec -T postgres pg_restore -U sunscrypt -d sunscrypt --clean --if-exists < backups/<файл>.dump
$C up -d
```

Копии лежат на том же сервере. Для защиты от потери сервера нужна копия
вовне (например, Google Диск владельца) — отдельное решение.

## Модель (этап 8)

- Реестр: `/opt/sunscrypt/models/registry/<версия>`, текущий чемпион — файл
  `registry/CHAMPION`; сервис сигналов переключается сам.
- Выпуск — только если претендент на последних 4 неделях (которых не видел)
  после комиссий лучше чемпиона, моментума и «не торговать».
- Дрейф: живые сигналы против ожидания с истории; при отклонении больше 3
  стандартных ошибок — откат на прошлую версию, нет её — пауза Kronos
  (снять — кнопкой в админке).

## Ручные запуски (GitHub Actions, репозиторий DevUZ-perfect-, ветка sunscrypt)

Секреты сервера пока заведены там, поэтому кнопки — там же:

- **SUNSCRYPT — выкатка** — выкатить свежий `main`;
- **SUNSCRYPT — состояние движка** — кабинеты, сделки, сверка, журнал задач;
- **SUNSCRYPT — задача модели** — дообучение или контроль дрейфа вне расписания.
