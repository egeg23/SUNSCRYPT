# Telegram-бот SUNSCRYPT

Бота создаёт владелец в @BotFather (`/newbot`), затем вставляет тексты ниже командами
`/setdescription`, `/setabouttext`, `/setcommands`, `/setuserpic`. Токен — только в секреты сервера
(`SUNS_TELEGRAM_BOT_TOKEN`), не в чат и не в репозиторий.

## Имя и адрес
- **Бот:** @SUNSCRYPT_tradebot, имя «SUNSCRYPT Trader».
- **Установлено 06.10.2026 через Bot API:** аватар (`telegram-avatar-640.jpg`), description, short description.
- **Команды** (`setMyCommands`) включаем вместе с обработчиками на этапе 9, чтобы в меню не было неработающих кнопок.

## Аватар
`brand/assets/telegram-avatar-640.jpg` (640×640, JPG — Bot API принимает только JPG; солнце по центру, Telegram обрежет в круг).

## About (до 120 символов)
Уведомления о сделках робота SUNSCRYPT на Bybit: сделки, дневной отчёт, тревоги и аварийная остановка.

## Description (видно до нажатия «Старт», до 512 символов)
SUNSCRYPT — робот для торговли перпетуалами на Bybit.

Этот бот присылает:
• каждую сделку вашего кабинета;
• дневной отчёт: баланс, доля успешных сделок, просадка;
• тревоги: лимит убытка, обрыв связи с биржей, ошибка ключа.

Команда /stop мгновенно останавливает торговлю в вашем кабинете.
Сервис готовится к запуску: привязка бота появится в личном кабинете на сайте. Прибыль не гарантирована.

## Команды (/setcommands)
```
start - Привязать бота к кабинету SUNSCRYPT
status - Баланс, позиции и режим (демо или реальный)
report - Отчёт за сегодня
stop - Аварийно остановить торговлю в моём кабинете
help - Что умеет бот
```

## Приветствие после привязки
Готово, бот привязан к кабинету {email}.
Режим: {ДЕМО|РЕАЛЬНЫЙ СЧЁТ}. Пришлю каждую сделку и вечерний отчёт в 21:00 по Москве.
Остановить торговлю: /stop.
